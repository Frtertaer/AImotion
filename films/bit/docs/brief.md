# BIT — director's brief

## Film in one line
Курсор в тёмном терминале рассыпается на пиксели и собирается в маленькое оранжевое существо Bit,
которое бегает, размножается, складывается в собственное имя и снова прячется в курсор. Зритель
должен улыбнуться и захотеть пересмотреть: последний кадр = первый.

## Reference
`refs/screenshot.png` (скрин пользователя): почти чёрный фон терминала, тонкая серая скруглённая рамка,
маленький оранжевый пиксельный персонаж. Берём грамматику (палитра, пиксельная сетка, тонкая рамка
терминала, моноширинный шрифт), НЕ берём конкретный спрайт — Bit оригинальный.

## Tools
Маршрут A (выбран Jev): `render.mjs` + `lib/motion.js`. Музыка — `chiptune.mjs` плагина claude-animation,
измерение бита — `audio/beats.py`, SFX — `audio/sfx.mjs` из `timeline.js`, сведение — `audio/mix.mjs`.
Критик — отдельный субагент, смотрит contact/strip/phone листы.
