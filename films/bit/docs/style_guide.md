# Style guide — BIT

## Palette
- bg `#151515` (терминал, снято с refs/screenshot.png), рамка `#3A3936`, текст кода `#6E6B63`, текст яркий `#EDEBE4`
- Bit `#D77656` (тело, снято с референса), тень `#B35F42`, глаза `#151515`, блик `#EDEBE4`, кончик антенны `#F2C4A8`
- Акцент один: оранжевый Bit. Никаких градиентов, свечения, частиц-салютов.

## Type
- Один шрифт: моноширинный (Consolas → Cascadia Mono → monospace), 600.
- Большое слово набирается из пикселей Bit (шрифт 3×5 клеток), не шрифтом.

## Pixel grid
- Всё, что относится к Bit, живёт на сетке `P` (P = min(W,H)/27). Пиксели — квадраты без сглаживания.
- Пиксели не вращаются, только летят и масштабируются.

## Motion
- Пружины `lib/motion.js`: сборка пикселей — playful (видимый перелёт), камера/рамка — base,
  прыжки — парабола + squash/stretch при приземлении.
- Stagger сборки 0.012 с на пиксель, порядок — от центра.
- Каждые 2 с новое событие (1 такт при 120 BPM).

## Camera
- Статичная рамка терминала; в эпизоде бега — горизонтальный скролл мира (код и препятствия едут влево).

## Banned
Центрированный заголовок на градиенте, fade-in всего подряд, подписи в углах, рамки-виньетки.
Тонкая рамка терминала — это часть мира из референса, а не декоративная рамка кадра.
