# Style guide — SEEK

## Palette
- bg `#0C0E0B` (почти чёрный, тёплый хвост в зелёное)
- ink `#E9EFE2` (фосфорно-белый)
- dim `#5B6B54` (приглушённый зелёно-серый — сетка, второстепенный текст)
- line `#263024` (рейки, рамки ячеек)
- ACCENT `#A8FF3E` — один, кислотно-зелёный фосфор: playhead, spring, ключевые хиты
- warn `#FF4D2E` — только штампы "fix"/"fail" в критик-акт и стоп-кадры
- Никаких градиентов как заливки сцен, никакого свечения-блума на UI. Допускается
  "шлейф" — последовательные ghost-копии одного и того же объекта (это демонстрация массы, не свечение).

## Type
- Display: `Liberation Sans Narrow` 900 — огромный узкий кегль для кинетических слов.
- UI: `JetBrains Mono` 400/700 — таймкод, подписи, чипы, счётчики.
- Никакого третьего шрифта. Капслок для display.

## World
- Линейка: полоса внизу кадра (~12–14% высоты), 64 тика бита, каждый 4-й выше (такт),
  номера тактов приглушены. Playhead сканирует `t/DUR` по линейке весь фильм.
- Сцена — пространство над линейкой. Активная зона такта на линейке подсвечена accent-сегментом.

## Motion
- Только пружины `lib/motion.js` (FEEL + прямые k/d). `track()` для повторных целей.
- Overshoot виден и многократен там, где это сюжет (SPRING-акт, всплытия ячеек).
- Пружина-эталон рисуется ghost-шлейфом: 14 бусин на траектории, сгущающихся у цели.

## Camera
- Мир статичен; движение — внутри: scrub, вылеты, морфы. Единственный "камерный" трюк —
  REWIND: сканлайн заметает справа налево.

## Banned
Центрированный заголовок на градиенте; fade-in подряд; подписи по углам; декоративные
рамки кадра; типовые взрывы частиц; пиксель-арт (это территория bit).
