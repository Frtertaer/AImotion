# AImotion: студия моушн-дизайна из кода

Каждый ролик — программа, а не видео. Модель пишет страницу с `window.seek(t)`,
рендерер проходит по времени и собирает кадры в MP4 через ffmpeg.

## Раскладка
- `films/<name>/index.html` — фильм. Экспортирует `window.FILM = {w, h, dur}`,
  `window.seek(t)`, ставит `window.READY = true`. Канвас с `id="c"`.
- `lib/motion.js` — пружины (`spring`, `track`, `stretch`, `swapAlpha`), `rng`, биты.
- `render.mjs` — рендер. `tools/review.mjs` — листы для просмотра.
  `tools/check-seek.mjs` — проверка контракта seek на сырых пикселях.
- `audio/beats.py` (через `.venv`), `audio/sfx.mjs`, `audio/mix.mjs`.
- `films/demo` — рабочий пример, копировать как шаблон.

## Команды
```
node render.mjs films/<name> [--fps 60] [--sub 4] [--from 0] [--dur N] [--out path]
node tools/check-seek.mjs films/<name>
node tools/review.mjs films/<name>/out/final.mp4 [--at 4.2]
.venv/Scripts/python audio/beats.py track.wav > films/<name>/beats.json
node audio/sfx.mjs films/<name>/cues.json films/<name>/out/sfx.wav --dur N
node audio/mix.mjs films/<name>/out/silent.mp4 films/<name>/out/final.mp4 <wav...> [--lufs -14]
```
Python только из `.venv` (системный pip здесь не пишет в site-packages).

## Контракт рендера
- Кадр — чистая функция времени. Никаких CSS-transition, setTimeout, rAF в рендере,
  никакого состояния между кадрами. Случайность только через `rng(seed)`.
- Модули ES грузятся по http: рендер сам поднимает сервер на 127.0.0.1. Не открывать через file://.
- Шрифты: системные или локальные файлы в папке фильма. Без сетевых шрифтов в рендере.
- После правок движка или фильма: `check-seek` должен дать N/N.

## Вкус
- Запрещено: заголовок по центру на градиенте, всё появляется через fade-in,
  подписи в углах и рамки кадра, свечение на UI, типовые взрывы частиц.
- Один дисплейный шрифт, один UI-шрифт, один акцентный цвет, если бриф не говорит иначе.
- Каждые 2–4 секунды на экране происходит что-то новое. Первые 2 секунды — крючок.
- Движение на пружинах (`FEEL`), а не на кривых easing. Значение с несколькими целями — через `track`.

## Звук
- Если трек не дан — синтезировать кодом. Если дан — сначала `beats.py`, события ставить на биты.
- Цель громкости −14 LUFS. Проверять итоговой сводкой ebur128, а не первой строкой лога.

## Петля перед показом
1. Отрендерить (можно короткий кусок `--from/--dur`), запустить `review.mjs`, ОТКРЫТЬ и посмотреть
   contact.png, strip.png, phone.png.
2. Оценить 1–10: крючок, читаемость на телефоне, качество движения, разнообразие,
   композиция, соответствие бренду, синхрон со звуком.
3. Исправить три худшие проблемы с таймкодами. Повторять, пока все оценки не 8+.
4. Только потом полный рендер и сведение.

## Установленные инструменты
- Скиллы в `.claude/skills`: Remotion (`/remotion-*`) и HyperFrames (`/hyperframes`,
  `/product-launch-video`, `/music-to-video`, ...). Если бриф просит фреймворк — брать их,
  иначе маршрут A (этот движок).
- Плагин `claude-animation` (рисованная анимация на node canvas) — глобально, user scope.
