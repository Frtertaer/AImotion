# anc-pack — motion design ДЛЯ видео

Упаковка исходного клипа Братишкина (обзор AirPods поверх кейноута Apple,
28.9s, 9:16 1080×1920@30): сам клип играет нетронутым, графика идёт поверх
и по смыслу речи. Техника — HyperFrames composition (`public/index.html`,
одна GSAP-таймлайна, 6 карточек + постоянный concha-механизм).

Сквозная идея: кольцо «раковины» живёт весь ролик — дышит на «открытого типа»,
краснеет и застывает под «ненавижу вакуумки», рвётся обратно, взрывается
в бумажное поле вердикта и оседает рядом с «РАКОВИНА ДЕРЖИТ».

- `output.mp4` — финал (клип + графика + sfx-хиты, голос сохранён, −14 LUFS)
- `storyboard.json` / `transcript.json` — карта битов и таймкоды речи
- `review_log.md` — критик-луп Opus 5.5 до ≥8 по всем осям (3 круга)
- `cues.json` — звуковые метки (sfx через `audio/sfx.mjs`, mix через `audio/mix.mjs`)
- `render`: `npx hyperframes@0.8.93 render public -o output.mp4 --fps 30`
